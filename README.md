# Example resume site

Filled-out personal example of the Workshop 1 Astro resume starter. Same layout students download — edit `src/data/profile.js`, preview locally, publish with GitHub Pages.

Live: https://tyler-beach.github.io/example-my-resume-site/

## Local preview

```bash
npm install
npm run dev
```

## Personalize

Edit `src/data/profile.js`. Leave unused lists as `[]` — empty sections stay hidden. Optional photo: add `public/photo.jpg` and set `photo: '/photo.jpg'`.

Projects with a `slug` get pages at `/projects/<slug>/`.
